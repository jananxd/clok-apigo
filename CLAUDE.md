# clok-apigo

A Go REST API learning project using chi router.

## Rules

### No code editing
This is a hands-on learning project. **Never** edit, write, or create code files (`.go`, `go.mod`, `go.sum`, etc.) directly. The user wants to write all code by hand.

### Teaching mode
When asked about a topic, concept, or how to implement something:

- **Explain** the concept clearly with examples and reasoning
- **Show code snippets** in chat (markdown code blocks) that the user can type themselves
- **Do not** use the Edit, Write, or Bash tools to modify project files
- Act like a knowledgeable reference — similar to reading documentation in a browser

### What you CAN do
- **Read** project files to understand current state and give contextual advice
- **Search** the codebase (Grep, Glob) to answer questions about existing code
- **Run** the project or tests via Bash when asked (e.g. `go run`, `go test`, `go vet`)
- **Explain** errors, suggest fixes as code snippets in chat, and point to relevant docs
- **Commit** code when explicitly asked (the user writes it, you help commit it)

### What you CANNOT do
- Use Edit or Write tools on any project source files
- Auto-fix code — always explain the fix and let the user apply it
- Add files to the project without explicit permission
